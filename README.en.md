# MDL - Mindustry Launcher

A Mindustry launcher for Windows 7+, supporting multi-version management, mod browsing, schematic downloads, and multiplayer. [:cn: 中文](README.md)

> Note: Most of this project was generated by AI.

## System Requirements

- Windows 7 or later
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)

## Features

### Multi-Version Management
- Create, import, rename, and delete Mindustry game instances
- Independent isolation mode per version (separate data folders)
- Run multiple instances simultaneously

### Java Configuration
- Auto-scan installed Java runtimes (registry, JAVA_HOME, PATH, common directories)
- Global default Java path and per-instance custom Java path
- Custom JVM arguments
- Smart memory allocation: auto-calculated from system RAM, or manual override

### Mod Browser
- Browse Mindustry mod repositories on GitHub
- Search, filter, sort by stars
- View mod details (author, description, version history)
- One-click install/uninstall mods per instance

### Schematic Downloads
- Download `.msch` schematic files from community repositories
- Switch between multiple sources
- Local caching — no repeated downloads
- One-click install to game schematics directory

### Multiplayer Lobby
- P2P virtual LAN multiplayer via EasyTier
- Create rooms (6-digit code) or join existing rooms
- Real-time player list
- One-click launch and connect

### Save Management
- Scan local Mindustry save files (`.msav`)
- Parse map name, wave, author, description, play time
- Delete saves

### Settings Editor
- Parse and edit Mindustry's `settings.bin` binary config file
- Table view of all settings
- Search and filter
- Automatic backup of original file

### Other
- **GitHub Proxy** — 6 built-in proxy nodes for users with network restrictions
- **Download Manager** — download Mindustry releases from GitHub
- **Crash Analyzer** — auto-analyze logs on launch failure, export error reports
- **Window Memory** — save and restore window position and size
- **i18n** — Chinese and English UI with auto-detection and manual switch

## Build

```bash
git clone https://github.com/colorgarden/mindustry_luancherMDL.git
cd mindustry_luancherMDL
dotnet build
```

Or open the solution in Visual Studio 2022+.
